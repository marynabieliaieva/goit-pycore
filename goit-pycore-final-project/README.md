# Personal Assistant

Фінальний проєкт курсу «Python Programming: Foundations and Best Practices 2.0» (GoIT): **«Персональний помічник»** з інтерфейсом командного рядка. Зберігає контакти (імена, телефони, email, адреси, дні народження) і текстові нотатки з тегами.

## Можливості

**Контакти**
- Додавання контактів з іменем, телефонами, email, адресою та днем народження.
- Валідація кожного поля: телефон (рівно 10 цифр; пробіли, дефіси та дужки можна вводити, вони відкидаються), email (`name@domain.tld`), дата (`DD.MM.YYYY`, не в майбутньому), ім'я та адреса (не порожні, з обмеженням довжини). Некоректне значення не зберігається, а помічник пояснює, що не так.
- Пошук за будь-яким полем: ім'я, телефон (за цифрами, `050-123` знайде `0501234567`), email, адреса, дата народження.
- Редагування (телефони, email, адреса, день народження, перейменування) і видалення.
- Список контактів, у яких день народження в найближчі N днів (`birthdays 30`).
- Ім'я шукається без урахування регістру: `anna` і `Anna` означають один контакт.

**Нотатки**
- Додавання текстових нотаток; слова на кшталт `#work` у тексті стають тегами.
- Пошук за текстом і тегами, редагування та видалення.
- *Додатковий функціонал:* теги, пошук нотаток за одним або кількома тегами, сортування нотаток за тегами, список усіх тегів.

**Інше**
- Дані зберігаються на диску в папці користувача й не губляться після перезапуску.
- Неправильне введення ніколи не закриває програму. На помилку в назві команди помічник підказує схожі (`phne` → `phone`).
- Без зовнішніх залежностей, тільки стандартна бібліотека Python 3.9+.

## Встановлення

Потрібен Python 3.9 або новіший.

```bash
git clone https://github.com/marynabieliaieva/goit-pycore.git
cd goit-pycore/goit-pycore-final-project
pip install .
```

Після встановлення помічник запускається з будь-якої папки:

```bash
personal-assistant
```

Коротка команда `assistant` теж працює, як і `python -m personal_assistant`.

Для розробки можна встановити пакет у режимі редагування (`pip install -e .`, потрібен pip 21.3+). Видалити пакет: `pip uninstall personal-assistant`.

## Де зберігаються дані

У папці `~/.personal_assistant` (на Windows: `C:\Users\<ім'я>\.personal_assistant`):

| Файл | Що містить |
| --- | --- |
| `contacts.pkl` | Адресна книга |
| `notes.pkl` | Нотатки |

Дані записуються після кожної команди, що їх змінює, і ще раз при виході (також при Ctrl+C). Запис атомарний, тож перерваний запис не псує файл. Якщо файл пошкоджений, помічник зберігає його як `.bak` і починає з порожньої книги.

Іншу папку можна задати змінною середовища `PERSONAL_ASSISTANT_HOME`.

## Команди

Аргументи в `< >` обов'язкові, у `[ ]` необов'язкові. Ім'я з пробілом беріть у лапки: `add "Anna Maria"`. `help <команда>` показує довідку та синоніми команди.

### Контакти

| Команда | Що робить |
| --- | --- |
| `add <ім'я> [телефон]` | Створити контакт (або додати телефон до наявного) |
| `add-phone <ім'я> <телефон>` | Додати телефон |
| `change-phone <ім'я> <старий> <новий>` | Замінити телефон |
| `remove-phone <ім'я> <телефон>` | Видалити телефон |
| `set-email <ім'я> <email>` | Задати або змінити email |
| `remove-email <ім'я>` | Видалити email |
| `set-address <ім'я> <адреса...>` | Задати або змінити адресу (може містити пробіли) |
| `remove-address <ім'я>` | Видалити адресу |
| `set-birthday <ім'я> <DD.MM.YYYY>` | Задати або змінити день народження |
| `remove-birthday <ім'я>` | Видалити день народження |
| `rename <ім'я> <нове ім'я>` | Перейменувати контакт |
| `delete <ім'я>` | Видалити контакт |
| `show <ім'я>` | Усі дані контакту |
| `phone <ім'я>` | Телефони контакту |
| `show-birthday <ім'я>` | День народження та скільки днів до нього |
| `all` | Усі контакти за абеткою |
| `find <текст>` | Пошук контактів за будь-яким полем |
| `birthdays [днів]` | Дні народження в найближчі N днів (за замовчуванням 7) |

### Нотатки

| Команда | Що робить |
| --- | --- |
| `add-note <текст...> [#тег ...]` | Додати нотатку; слова з `#` стають тегами |
| `notes` | Усі нотатки |
| `show-note <id>` | Одна нотатка |
| `edit-note <id> <новий текст...> [#тег ...]` | Замінити текст (нові `#теги` додаються) |
| `delete-note <id>` | Видалити нотатку |
| `find-note <текст>` | Пошук за текстом і тегами |
| `add-tag <id> <тег> [тег ...]` | Додати теги |
| `remove-tag <id> <тег>` | Видалити тег |
| `find-tag <тег> [тег ...]` | Нотатки, що мають усі вказані теги |
| `sort-notes` | Нотатки, відсортовані за тегами (без тегів у кінці) |
| `tags` | Усі теги та номери нотаток з ними |

### Загальні

| Команда | Що робить |
| --- | --- |
| `hello` | Привітання |
| `help [команда]` | Список команд або довідка по одній |
| `exit` / `close` / `quit` | Зберегти дані й вийти |

```text

>>> add Anna (050)123-45-67

>>> set-email Anna anna@
Invalid email 'anna@'. Use the form name@example.com.
>>> set-email Anna anna@example.com

>>> set-address Anna Kyiv, Khreshchatyk 1

>>> set-birthday Anna 11.11.1995
Birthday of 'Anna' set to 11.11.1995.
>>> birthdays 5
Birthdays in the next 5 days:
  Anna: 11.11 (in 3 days)
>>> add-note Prepare demo slides #work #python

>>> find-tag python

    Prepare demo slides
>>> phne Anna
Unknown command 'phne'. Did you mean: phone, add-phone, change?
>>> exit
Good bye!
```

Після повторного запуску `all` і `notes` покажуть ті самі дані.

## Структура проєкту

```text
goit-pycore-final-project/
├── pyproject.toml              # метадані пакета та команди personal-assistant / assistant
├── README.md
├── personal_assistant/
│   ├── __init__.py
│   ├── __main__.py             # python -m personal_assistant
│   ├── main.py                 # цикл команд, розбір введення, підказки
│   ├── commands.py             # обробники команд, реєстр команд, help
│   ├── fields.py               # поля з валідацією: Name, Phone, Email, Address, Birthday, NoteText, Tag
│   ├── contacts.py             # Record і AddressBook
│   ├── notes.py                # Note і NoteBook
│   └── storage.py              # збереження та завантаження через pickle
└── tests/
    └── test_assistant.py
```

**ООП:** усі поля успадковуються від `Field`, і кожне перевіряє своє значення в конструкторі. `Record` і `Note` складаються з цих полів (композиція). `AddressBook` і `NoteBook` успадковуються від `UserDict`. Команди реєструються декоратором `@command`, а декоратор `input_error` перетворює помилки введення на повідомлення.
