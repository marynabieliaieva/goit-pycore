# goit-pycore-hw-07

Домашнє завдання до Теми 10 курсу «Python Programming: Foundations and Best Practices 2.0»: консольний бот-помічник на основі класів адресної книги.

| Файл | Що містить |
| --- | --- |
| `address_book.py` | Класи `Field`, `Name`, `Phone` (10 цифр), `Birthday` (DD.MM.YYYY), `Record`, `AddressBook` з методом `get_upcoming_birthdays` |
| `main.py` | Бот: обробники команд з декоратором `input_error`, цикл `main()` |

## Команди

| Команда | Що робить |
| --- | --- |
| `add [ім'я] [телефон]` | Додати новий контакт або телефон до наявного |
| `change [ім'я] [старий телефон] [новий телефон]` | Змінити телефон контакту |
| `phone [ім'я]` | Показати телефони контакту |
| `all` | Показати всі контакти |
| `add-birthday [ім'я] [DD.MM.YYYY]` | Додати дату народження |
| `show-birthday [ім'я]` | Показати дату народження |
| `birthdays` | Дні народження на наступні 7 днів (вихідні переносяться на понеділок) |
| `hello` | Привітання |
| `close` / `exit` | Вийти з програми |

Зовнішніх залежностей немає, потрібна тільки стандартна бібліотека Python 3.9+.

## Запуск

```bash
python main.py
```
